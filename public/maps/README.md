# India state boundaries

`india-states.geojson` is a locally hosted copy of the simplified state/UT layer from:
https://static.geodataviewer.com/datasets/india-states.geojson

Source: DataMeet via geoBoundaries. License: Creative Commons Attribution 2.5 India.
https://creativecommons.org/licenses/by/2.5/in/
Dataset information: https://geodataviewer.com/datasets/boundaries/india-states-boundaries/

State names are normalized for display only; source geometries are retained. This is a reference boundary layer, not a survey record. GPS markers always use actual measured coordinates.
